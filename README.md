# 📖 사용 설명서 (User Manual)

개발에 익숙하지 않아도 괜찮아요! 아래 순서대로 따라하면 쉽게 블로그를 업데이트할 수 있습니다.

## 1. WebStorm에서 업데이트 하기 (내 컴퓨터에서 저장)

작업한 내용을 저장하고 GitHub에 올리는 과정입니다.

### 1단계: 커밋 (Commit) - 저장하기
내가 수정한 파일을 기록하는 단계입니다.
1. 단축키 **`Command` + `K`** 를 누릅니다.
2. 왼쪽 'Commit' 탭이 열리면, 수정된 파일들이 체크되어 있는지 확인합니다.
3. 아래쪽 메시지 입력창에 **어떤 작업을 했는지** 간단히 적습니다. (예: "블로그 글 추가", "오타 수정")
4. **[Commit]** 버튼을 클릭합니다.

### 2단계: 푸시 (Push) - 서버로 보내기
내 컴퓨터에 저장된 기록을 GitHub(인터넷)로 보내는 단계입니다.
1. 단축키 **`Command` + `Shift` + `K`** 를 누릅니다.
2. **[Push]** 버튼을 클릭합니다.
   - 이때 "Push Successful" 메시지가 나오면 GitHub에 안전하게 올라간 것입니다.

## 2. 블로그 배포하기 (인터넷에 반영)

수정한 내용이 실제 `king-miro.github.io` 사이트에서 보이게 하려면 **배포(Deploy)** 과정을 거쳐야 합니다.

1. WebStorm 하단에 있는 **Terminal** (터미널) 탭을 클릭합니다.
   - 만약 없다면 메뉴에서 `View` > `Tool Windows` > `Terminal`을 선택하세요.
2. 터미널 창에 아래 명령어를 복사해서 붙여넣고 **엔터(Enter)** 키를 누릅니다.
   ```bash
   npm run deploy
   ```
3. 글자들이 쭉 나오면서 배포가 진행됩니다. 
   - 마지막에 `Published` 라는 문구가 나오면 성공입니다! 🎉
4. 잠시 후(약 1~2분) 블로그 주소로 들어가면 바뀐 내용을 볼 수 있습니다.
